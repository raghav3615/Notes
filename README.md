# My Todo App

A modern, minimal to-do list application designed for productivity and developer needs. This application features a dark theme and a clean user interface, focusing on essential functionalities without unnecessary AI elements.

## Features

- Add, remove, and mark todos as completed.
- Switch between light and dark themes.
- Persistent storage using local storage.
- Minimal and modern UI design.

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm (Node Package Manager)

### Installation

1. Clone the repository:

   ```
   git clone https://github.com/yourusername/my-todo-app.git
   ```

2. Navigate to the project directory:

   ```
   cd my-todo-app
   ```

3. Install the dependencies:

   ```
   npm install
   ```

### Running the Application

To start the development server, run:

```
npm run dev
```

Open your browser and go to `http://localhost:3000` to view the application.

### Building for Production

To build the application for production, run:

```
npm run build
```

The built files will be available in the `dist` directory.

## Usage

- Use the input field to add new todos.
- Click on the checkbox to mark a todo as completed.
- Click the delete button to remove a todo from the list.
- Use the theme toggle to switch between light and dark modes.
